# Five-Yonkous
Suíte offensive para segurança web com scanners integrados: detecção de secrets (API keys, tokens), análise de parâmetros com payloads generativos (XSS, SQLi, RCE), identificação de exposição de dados sensíveis (PII, .env, logs) e misconfigurations (headers, CORS, arquivos críticos). Automação, precisão e foco ofensivo.
